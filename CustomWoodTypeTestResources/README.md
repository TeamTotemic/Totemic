This folder is a resource pack to test adding resources to two custom Totem Wood types with IDs `gametest:test_wood_type_1`
and `gametest:test_wood_type_2`, as added in [this config file](../run-gameTestServer/config/totemic-common.toml).
It also doubles as an example for adding resources to custom Totem Wood Types.

Each Totem Wood Types requires two block model files and two langauge keys, for the corresponding Totem Pole and Totem Base blocks.
